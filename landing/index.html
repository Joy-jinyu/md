A WYSIWYG Markdown editor that keeps your files plain

Pairdown formats Markdown as you type, in your browser. What it saves is ordinary Markdown text: open the file in any other editor and it reads the same, and the blocks you didn't touch are written back byte for byte.

Open the editor Source on GitHub

What you can do

  • Write with formatting in place

    Headings, lists, links, quotes and tables render as you write. Switch to the Markdown source at any time. Find and replace, an outline, focus mode and typewriter mode are built in.

  • Keep plain .md files

    Pairdown stores Markdown, not a private format. Edited blocks are written in one consistent style, and syntax it doesn't recognize is kept exactly as it was.

  • Tables, math and diagrams

    Tables, TeX math, footnotes, front matter, highlights, subscript and superscript, and Mermaid diagrams, which are drawn as images.

  • Your files, on your disk

    With the optional local gateway, Pairdown edits the .md files in a folder on your computer and puts pasted images in an assets folder beside them. Without it, documents stay in your browser.

  • Sync through GitHub

    Sign in with GitHub to keep each document in a secret Gist. When both copies changed, or one was deleted, Pairdown asks before it overwrites anything.

  • Open, save and export

    Import .md files, save a copy as .md, or export HTML with images included. Version history is kept on your device.

Get started

  1. Open the editor and start writing. There is no account to create; documents are saved in this browser.
  2. To work with files on your disk, install the local gateway (it needs Node.js 23.6 or later): 
    curl -fsSL __PAIRDOWN_SITE__/gateway.sh | sh
  3. To sync, choose Sync in the editor and sign in with GitHub.

Questions

Is Pairdown free?
Yes. The editor runs in your browser and doesn't need an account.
Where are my documents stored?
In your browser's storage, or as .md files in a folder on your computer when the local gateway is running. Pairdown has no server that keeps your documents. Synced copies go to Gists in your own GitHub account.
Will Pairdown rewrite my Markdown?
Blocks you don't edit are saved back byte for byte. A block you change is written in a consistent style, so saving it again gives the same text.
What does GitHub sync have access to?
Pairdown asks only for the gist permission. Signing out removes the sign-in from your device. Images don't sync yet.
Is there a desktop app?
A macOS app can be built from the source code. There is no download yet.
