# a11y 提示 role 使用规范

## 规则

- **role="alert"**：会影响文档安全/内容完整性的提示
  - 冲突条（ConflictBar）
  - 存储/连接中断（StorageNotice）
  - 其他可能丢失数据的严重警告

- **role="status" 或无 role**：一般信息/进度提示
  - 操作成功（已保存、已复制）
  - 进度更新
  - 非关键信息

- **避免同时多个 alert**：同屏多个提示时，alert 限一个，其他用 status

- **文案直达要点**：accessibilityLabel/ARIA 文案避免技术细节，直接说明问题和操作

## 实现检查清单

- [ ] 新增提示组件时根据严重程度选择 role
- [ ] 已有组件保持现有 role 不变（变动需 UX 评估）
- [ ] 测试：屏幕阅读器能正确朗读提示
