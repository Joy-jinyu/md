# Pairdown changelog

## v0.1.0

First public preview for Web and macOS (Apple silicon).

- Edit Markdown visually or in source mode, with support for tables, footnotes, formulas, and Mermaid diagrams.
- Keep documents in a browser or local file library, browse local version history, and export to Markdown or HTML.
- Optionally sync Markdown through private GitHub Gists or connect the web editor to a local library through the gateway.

The macOS download has an ad hoc signature. After verifying the downloaded ZIP against the SHA-256 checksums, unzip it and try opening Pairdown. If macOS blocks the first launch, use **System Settings → Privacy & Security → Open Anyway**. [Apple’s instructions](https://support.apple.com/en-us/102445) explain the confirmation.

The Web ZIP contains static files for serving at the root of a web server. Use the hosted editor for the configured GitHub sign-in and gateway integration.
